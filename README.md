# Carbon Emission Dataset: Exploratory Data Analysis

Advanced Python Project 2025/2026, by Abdullah Khalid Alsaleh

Exploratory analysis of the Carbon Emission dataset (50 companies, daily records, 2024): cleaning, univariate and bivariate analysis, time series, and five analytical questions.

Dataset: https://www.kaggle.com/datasets/freshersstaff/carbon-emission-forecasting-dataset

Files:
- Carbon_Emission_EDA.ipynb : the analysis
- carbon_emission_dataset_with_Industry.csv : the data
- figures : charts saved by the notebook
- requirements.txt : libraries
- Carbon_Emission_Report.pdf : the report

How to run: install the libraries with `pip install -r requirements.txt`, start `jupyter notebook`, open the notebook and use Kernel, Restart and Run All.

The dataset has no temperature or region column, so the temperature items were not done. Sector and industry were used for the group analysis.
